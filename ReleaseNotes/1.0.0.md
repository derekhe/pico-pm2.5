![Pico PM2.5 dashboard preview](https://raw.githubusercontent.com/derekhe/pico-pm2.5/master/docs/images/ui-preview.png)

- Adds a four-page Chinese dashboard for live PM2.5, particle details, 10/30/60-minute trends, and device status.
- Supports the existing GP4/GP5 PMS7003 wiring and automatically detects compatible GP0/GP1 wiring.
- Adds a 30-second warm-up, disconnect indication, automatic sensor recovery, and USB CDC diagnostics.
- Shows a rolling one-hour PM2.5 reference IAQI based on HJ 633—2026, with estimated and complete-hour labels.
- Includes a ready-to-flash Raspberry Pi Pico UF2 built with Pico SDK 2.3.1.

- 新增四页中文仪表盘，显示实时 PM2.5、颗粒物明细、10/30/60 分钟趋势和设备状态。

- 按 HJ 633—2026 显示滚动一小时 PM2.5 参考 IAQI，并区分预估值与完整小时值。
